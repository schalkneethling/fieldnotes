# Fieldnotes agent guidance

- Read `plans/README.md`, the active plan, and `plans/decisions.md` before substantial work.
- Never commit or push directly to `main`. Create or use a `codex/` branch and deliver changes through a pull request.
- Keep executable work in GitHub Issues and record durable product or technical decisions in `plans/decisions.md`.
- When a file has a size limit, check its size before reading it and retain a post-read byte check where race or encoding differences matter.
